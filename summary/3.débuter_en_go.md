# Débuter en Go

Nous allons voir comment installer et créer votre premier programme en go.

Pour installer Go, rendez vous sur : dev.go, puis cliquez sur download

Ensuite, si vous avez un mac téléchargez le fichier .pkg, correspondant à l'architecture de votre processeur : ARM64, si vous avez un mac équipé d'une puce M1, M2, M2 ou M4

X86, si vous avez un ancien mac.

Si vous avez un windows, téléchargez le .msi correspondant à l'architecture de votre processeur.

Une téléchargez , ouvrez le fichier puis suivez les instructions.

Une fois terminé, vérifiez l'installation , en vous rendant sur le terminal et en tapant go version dans votre terminal , vous devrez voir : la version de go dans une output ressemblant à ceci :

go version go1.26.6 darwin/arm64
