# Go Learning

Ce repository vous permet d'apprendre le langage Go à l'aide d'exemples de code, d'exerices et de notes sur le langage.

## Il est organisé de la manière suivante :

- Un dossier internal contenant : les différents exemples de code, inculant les explications

- Un dossier exercices contenant : Les exercices sous formes de fichier .md

- Un dossier summary contenant : des notes sur le langage, vous permettant d'enrichir votre connaissance du langage.

- Un dossier programs contenant : des consignes de programmes à écrire, du plus simple au plus compliqué, sous formes de fichiers .md. Le code de ces programmes ne doit jamais être écrit dans ce repo : chaque consigne rappelle de créer un nouveau dossier à part, avec son propre go.mod.
